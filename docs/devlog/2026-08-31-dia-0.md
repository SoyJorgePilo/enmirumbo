# 2026-08-31 · Día 0: arranca NecesitoUno

**Hito:** el proyecto pasó de PRD a repositorio con proceso de desarrollo definido, en un día.

## Qué construimos

Hoy no hay producto todavía — hay algo igual de importante: la fábrica. NecesitoUno será el directorio de negocios de Tizayuca: los negocios se registran solos desde el celular en menos de 5 minutos, un admin los verifica de vecino a vecino, y la gente los encuentra y les escribe directo por WhatsApp.

Lo que quedó listo hoy:

- El PRD versionado en el repo (7 versiones de refinamiento con investigación de mercado real: INEGI, competencia, marco legal LFPDPPP 2025).
- El backlog completo del MVP: 9 épicas, ~30 historias, priorizadas P0/P1.
- El esqueleto técnico: Next.js + TypeScript + Tailwind, elegido por una razón concreta — las páginas "plomero en Tizayuca" tienen que indexar en Google y cargar en menos de 2 segundos en el 4G de la combi.
- El proceso de desarrollo con agentes de IA: cada feature viaja de ticket → especificación (OpenSpec) → implementación por agentes → pull request, con dos puntos de control humanos que no se saltan nunca (aprobar la spec y mergear el PR).

## La decisión interesante

Este proyecto se construye **en público**: el repo es abierto desde el día 0 y cada feature terminada deja una entrada como esta. La apuesta es doble: documentar en serio cómo se construye un producto real con un flujo multiagente, y que ese mismo contenido sirva para dar a conocer el directorio antes de lanzarlo.

## Qué aprendimos

Que el orden importa: definir el proceso ANTES de escribir la primera línea de código cuesta unas horas y evita el clásico "el agente hizo algo que nadie pidió". Las specs baratas de corregir son las que aún no tienen código encima.
